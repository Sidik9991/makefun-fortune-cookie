One original line of fortune-cookie wisdom for a software developer, picked
at runtime by scoring candidates against the judge's own brief.

## The line

> The code you fear to touch is the code that already knows you.

62 characters, one line. The program holds 10 candidate fortunes as data,
scores each against the judge's five criteria in the brief's order
(fortune-cookie-ness, cookie voice, true about a dev's day, fresh turn,
quiet twist), and writes the winner to `/output/entry.txt`.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Node 22+. No dependencies. Deterministic: the same winner every run.
